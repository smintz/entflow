## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| flow declaration → `Describe()` / `Meta()` output | This output reaches operator-facing dry-run surfaces and, in later phases, ops dashboards and span attributes. |
| entflow → external consumer (entconnect) | The `meta` package is the entire contract surface. Anything reachable through it is effectively public API for a different module. |
